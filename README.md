## The Equipment (What You're Actually Getting)

Deep Sentinel offers two main camera systems, and which one you choose depends on your needs:

### Wireless DS2 Camera System

This is the most popular option for homes and smaller businesses. The cameras are completely wireless—they run on rechargeable batteries, so you're not running cables all over your house.

Key specs that actually matter:
- 1080p Full HD recording (the newer DS2 models can handle even higher resolution)
- Color night vision with mini-floodlight
- 130-degree field of view
- Two-way audio
- 102-decibel siren built in
- IP65 weather rating (basically, it can handle getting blasted with a hose from any angle)

Installation? About 30 minutes if you can use a screwdriver and follow instructions on an app. Each camera mounts with literally one screw.

### Power-over-Ethernet (PoE) Camera System

This is for larger properties—think warehouses, construction sites, car dealerships, or bigger commercial buildings. These cameras are hardwired, which means:
- Faster data transmission
- 2K and 4K video quality options
- No batteries to recharge ever
- Requires professional installation (which Deep Sentinel can arrange)

Both systems use the same smart hub—a box about the size of a small router that runs the AI processing locally. It analyzes video at 30 frames per second, which is how the system can tell the difference between your teenager sneaking out and an actual threat.
